MHA as Agent Payment Settlement Asset

x402-Compatible Payment Flow

MAGNE Agent Pay uses MHA-supported assets (mMHA test token on testnet) as settlement. AI agents call a service → receive HTTP 402 with payment metadata → authorize wallet → MHA asset transfers on M Hash L2 → facilitator verifies → AI Task Receipt created on-chain.

This is a developer demo. MHA mainnet listing and production settlement are subject to governance and compliance requirements.

Why on M Hash L2?

M Hash L2 is designed to settle Agent Pay transactions with low cost and fast finality. Public performance metrics will be published as testnet validation progresses.
