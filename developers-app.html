Build with MAGNE Agent Pay

x402-compatible payment flows for AI agents. Fork the demo, read the SKILL.md, ship your integration.

Quick Start

$ git clone https://github.com/jerrysohigh-create/magne-agent-pay-demo
$ cd magne-agent-pay-demo/contracts
$ npm install
$ npx hardhat compile

// Deploy to M Hash L2 Testnet
$ npx hardhat run scripts/deploy.js --network mhashL2Testnet
