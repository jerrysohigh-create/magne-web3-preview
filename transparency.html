Agent Pay: Verifiable by Design

Every MAGNE Agent Pay transaction creates an immutable on-chain receipt. Verification does not depend on trusted intermediaries — any party can independently audit the full payment history on M Hash L2.

Immutable Receipts

AI Task Receipts are recorded on M Hash L2 via the AITaskReceipt smart contract. Each receipt contains: receiptId, taskId, user, provider, amount, token, paymentTxHash, and timestamp. Receipts cannot be altered or deleted after creation.

Strict Facilitator

The facilitator does not accept any successful transaction as proof of payment. It strictly verifies amount, recipient address, token contract, and chainId against expected values before marking a payment as verified. No exceptions.

On-Chain Settlement

All settlement happens on M Hash L2 (chainId: 20250827). Block explorer links are published for every verified transaction. This is a testnet-stage demo — mainnet deployment is subject to security audit and governance approval.
