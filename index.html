AI Task Receipt

Every payment creates an immutable AI Task Receipt on M Hash L2. Programmable. Verifiable. Auditable by any party.

The receipt event structure:

  address token,
  bytes32 paymentTxHash,
  uint256 timestamp
);

Compatibility Roadmap

MAGNE Agent Pay is aligned with the emerging open x402 standard and AP2-style authorization awareness. Not a Coinbase partnership — a developer demo for the broader ecosystem.

P0 — Must Align

x402 Foundation / Linux Foundation P0

Aligned with emerging open x402 standard (not Coinbase-specific). x402 Foundation announced April 2026 under Linux Foundation.

Google AP2 / Authorization P0

AP2-style authorization / trust layer. MAGNE Phone as secure authorization terminal with TEE/SE-backed signing.

MAGNE Facilitator P0

M Hash L2-oriented facilitator module. Not a replacement for global x402 facilitators — secure mobile auth + AI Task Receipt.

USDC / Stablecoin Support P0

V0.1: mMHA local. V0.2: mMHA on M Hash L2. V0.3: stablecoin-style asset. V1.0: USDC-compatible if bridge/liquidity ready.

P1 — Reference Align

Base / CDP Pattern P1

Reference align with Coinbase CDP Facilitator pattern: verify / settle / KYT flow.

BNB Chain / Binance P1

Preserve Binance ecosystem compatibility narrative for future multi-chain alignment.

Solana P1

Solana Web3 phone as competitor reference. x402.org test facilitator supports Solana Devnet.

P2 — Observe / Future

Stripe Tempo / MPP P2

Enterprise-grade machine payments / session pre-authorization. Future roadmap may explore.

OpenAI ACP P2

Agent-to-merchant checkout. Future roadmap may explore merchant interoperability.
