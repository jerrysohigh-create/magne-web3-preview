AI Task Receipt

Every payment creates an immutable AI Task Receipt on M Hash L2. Programmable. Verifiable. Auditable by any party.

The receipt event structure:

// AITaskReceiptCreated Event
event AITaskReceiptCreated(
  bytes32 receiptId,
  bytes32 taskId,
  address user,
  address provider,
  uint256 amount,
  address token,
  bytes32 paymentTxHash,
  uint256 timestamp
);
