Compatibility Roadmap

MAGNE Agent Pay is aligned with the emerging open x402 standard and AP2-style authorization awareness. Not a Coinbase partnership — a developer demo for the broader ecosystem.

P0 — Must Align

x402 Foundation / Linux Foundation P0

Aligned with emerging open x402 standard (not Coinbase-specific). x402 Foundation announced April 2026 under Linux Foundation with Coinbase, Cloudflare, Stripe, Google, Visa, Mastercard, Circle, AWS, Microsoft, Shopify, Solana Foundation, Polygon Labs, thirdweb.

Google AP2 / Authorization P0

AP2-style authorization / trust layer. MAGNE Phone as secure authorization terminal with TEE/SE-backed signing and agent spending controls.

MAGNE Facilitator P0

M Hash L2-oriented facilitator module. Not a replacement for global x402 facilitators — focuses on secure mobile authorization and AI Task Receipt creation.

USDC / Stablecoin Support P0

V0.1: mMHA local demo. V0.2: mMHA on M Hash L2. V0.3: stablecoin-style settlement asset. V1.0: USDC-compatible flow if bridge / liquidity ready.

Cloudflare / MCP / Agent Infra P0

MCP-style tool calls + HTTP 402 paid API. Cloudflare Agents SDK / MCP server integration. Paid inference API, wallet risk API, chain data API.

Wallet / Agent Wallet P0

EVM wallet compatible. TEE / Secure Element-backed signing. Agent spending policy controls. Future: WalletConnect, embedded wallet style.

P1 — Reference Align

Base / CDP Pattern P1

Reference align with Coinbase CDP Facilitator pattern: verify / settle / KYT flow. Base mainnet, Base Sepolia, Polygon, Arbitrum compatibility.

BNB Chain / Binance P1

Preserve Binance ecosystem compatibility narrative. BNB chain as reference for future multi-chain alignment.

Solana P1

Solana Web3 phone as competitor reference. x402.org test facilitator supports Solana Devnet. Solana as reference for multi-chain facilitator patterns.

OpenZeppelin Relayer P1

Enterprise relayer / audited infrastructure reference for future facilitator development.

OpenFacilitator / OpenX402.ai P1

Open source, self-deployed, permissionless facilitator as reference architecture.

P2 — Observe / Future

Stripe Tempo / MPP P2

Enterprise-grade machine payments / session pre-authorization. Future roadmap may explore session-based authorization.

OpenAI ACP P2

Agent-to-merchant checkout. Future roadmap may explore merchant checkout interoperability.

Stellar / Algorand / HyperEVM P2

Observe multi-chain facilitator patterns. No immediate integration planned.
