M Hash L2: Settlement Layer for Agent Pay

Why M Hash L2?

M Hash L2 is the settlement layer for MAGNE Agent Pay. Every payment — mMHA ERC20 transfer, facilitator verification, and AI Task Receipt creation — settles on M Hash L2.

AI Task Receipt

Every Agent Pay transaction produces an immutable on-chain receipt. The AITaskReceiptCreated event records: receiptId, taskId, user, provider, amount, token, paymentTxHash, timestamp.

Programmable by any smart contract or agent — no trusted intermediary required.
